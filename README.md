# Interactive 3D Techfest IIT Bombay Website

An interactive, premium 3D landing page for the 30th edition of **Techfest IIT Bombay 2026** (held on December 18-20, 2026). 

Built using React, Vite, Tailwind CSS, Three.js, and React Three Fiber.

## 🔗 Live Demo
Visit the live website here: [https://techfest26-seven.vercel.app/](https://techfest26-seven.vercel.app/)

## ✨ Key Features
* **3D Holographic Carousel:** A 3D circular slider showing IIT Bombay landmarks and event aftermovies.
* **Interactive Hover Effects:** Floating cards that tilt and react dynamically to your mouse cursor.
* **Click-to-Scroll Navigation:** Click on any 3D card to scroll smoothly to its details section.
* **Apple/Vercel Capsule Header:** Translucent pill-shaped navigation container with rounded capsule highlights.
* **Pulsing Status Indicator:** Quiet, minimal copyright footer showing a pulsing green system online dot.
* **Professional Slate Styling:** Clean, elegant dark-slate background with soft cool slate and warm champagne ambient lighting.
* **Authentic Content:** Real, specific events including Robowars, Boeing Aeromodelling, Sophia humanoid keynote talks, and the Startup Expo.

## 🚀 How to Run Locally

### 1. Clone the project
Download the files or clone the repository to your computer.

### 2. Install dependencies
Run this command in your project terminal:
```bash
npm install
```

### 3. Run the development server
Start the local server:
```bash
npm run dev
```
Open **http://localhost:5173/** (or the port outputted in your console) in your browser.

### 4. Build for production
Generate optimized static bundle:
```bash
npm run build
```
The output will be created inside the `dist/` directory.
